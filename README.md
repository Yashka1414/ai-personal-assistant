# ⚡ AI Personal Assistant

A lightweight multi-modal AI Assistant designed to automate daily productivity tasks like email drafting, document summarization, and quick search via both text and browser-native voice inputs.

## 🚀 Live Demo
🔗 [Click Here to View Live App](https://ai-personal-assistant-flg9u2eflftmveyp4hwt7x.streamlit.app)

## ✨ Features & Architecture
* **Task Automation:** Instant switching between general search/QA, automated email generation, and structured text summarization.
* **Voice-Enabled:** Integrated Web Speech API allowing hands-free voice commands directly from the browser.
* **LLM Engine:** Powered by **Groq Cloud API** running `llama3-70b-8192` for high-speed output generation.
* **Streamlit UI:** Zero-bloat interface with dynamic user prompts and secret session key management.

## 🛠️ Tech Stack
* **LLM API:** Groq API (`llama3-70b-8192`)
* **Voice Processing:** HTML5 Web Speech API
* **Frontend & Cloud:** Streamlit Cloud
